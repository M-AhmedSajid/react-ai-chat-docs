`next-ai-chatbot` gives you a ready-to-use chatbot UI with streaming responses, customizable themes, and server-side model integration.

## Why next-ai-chatbot?

Build a production-ready chatbot interface without spending days building the UI from scratch.

### Simple setup

Install the package and add the component to your application.

### Streaming responses

Display AI responses as they arrive for a responsive chat experience.

### Customizable

Control the appearance, behavior, prompts, and model configuration.

### React friendly

Use the component inside your React application and connect it to your own API.

## Quick example

```bash
npm install next-ai-chatbot
```

```
import { Chatbot } from "next-ai-chatbot";

export default function App() {
  return <Chatbot />;
}
```
