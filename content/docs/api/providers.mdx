# Providers

`react-ai-chat` supports multiple embedding providers for RAG.

Embedding providers convert text into vectors that can be compared to find relevant content.

The currently supported providers are:

- Google
- OpenAI
- Voyage
- Cohere
- Jina
- Hugging Face

The provider wrappers are included in `react-ai-chat`. Most providers use their official SDK as an optional peer dependency. Jina uses a client provided directly by `react-ai-chat`.

## How providers are used

Providers are used when creating your RAG embedding index and when retrieving relevant content during a chat request.

```text
Documents
   ↓
Embedding provider
   ↓
Embedding vectors
   ↓
Embedding index
   ↓
User question
   ↓
Query embedding
   ↓
Relevant chunks
```

The provider used to create an index should match the provider used to query that index.

## Google

Install the Google GenAI SDK:

```bash
npm install @google/genai
```

Set your API key:

```text
GOOGLE_GENERATIVE_AI_API_KEY=your_api_key_here
```

Create a Google GenAI client and pass it to `googleEmbedding()`:

```tsx
import { GoogleGenAI } from "@google/genai";
import { googleEmbedding } from "react-ai-chat/server";

const client = new GoogleGenAI({
  apiKey: process.env.GOOGLE_GENERATIVE_AI_API_KEY!,
});

const provider = googleEmbedding(client);
```

The default embedding model is:

```text
gemini-embedding-001
```

You can provide a different model:

```tsx
const provider = googleEmbedding(client, {
  model: "gemini-embedding-001",
});
```

## Jina

`react-ai-chat` includes its own Jina client, so you don't need to install a Jina SDK.

Set your API key:

```text
JINA_API_KEY=your_api_key_here
```

Create the client with `createJinaClient()`:

```tsx
import {
  createJinaClient,
  jinaEmbedding,
} from "react-ai-chat/server";

const client = createJinaClient({
  apiKey: process.env.JINA_API_KEY!,
});

const provider = jinaEmbedding(client);
```

The client communicates directly with the Jina embeddings API using `fetch()`.

The default base URL is:

```text
https://api.jina.ai/v1
```

You can provide a custom base URL:

```tsx
const client = createJinaClient({
  apiKey: process.env.JINA_API_KEY!,
  baseURL: "https://api.jina.ai/v1",
});
```

### Embedding model

The default model is:

```text
jina-embeddings-v3
```

You can provide a different model:

```tsx
const provider = jinaEmbedding(client, {
  model: "jina-embeddings-v3",
});
```

The provider uses different Jina tasks depending on the type of embedding:

```text
Document → retrieval.passage
Query    → retrieval.query
```

### Direct client usage

`createJinaClient()` returns a client with an `embeddings.create()` method.

```tsx
const response = await client.embeddings.create({
  model: "jina-embeddings-v3",
  input: ["Your text here"],
  task: "retrieval.query",
});
```

You normally don't need to call this method yourself. Pass the client to `jinaEmbedding()` and let the provider handle embedding requests.

## Hugging Face

Install the Hugging Face Inference SDK:

```bash
npm install @huggingface/inference
```

Set your API token:

```text
HF_TOKEN=your_api_token_here
```

Create an inference client and pass it to `huggingFaceEmbedding()`:

```tsx
import { InferenceClient } from "@huggingface/inference";
import { huggingFaceEmbedding } from "react-ai-chat/server";

const client = new InferenceClient(
  process.env.HF_TOKEN!,
);

const provider = huggingFaceEmbedding(client);
```

The default embedding model is:

```text
sentence-transformers/all-MiniLM-L6-v2
```

You can provide a different model:

```tsx
const provider = huggingFaceEmbedding(client, {
  model: "sentence-transformers/all-MiniLM-L6-v2",
});
```

## Provider overview

| Provider     | Package                    | Default model                            | Client               |
| ------------ | -------------------------- | ---------------------------------------- | -------------------- |
| Google       | `@google/genai`            | `gemini-embedding-001`                   | `GoogleGenAI`        |
| OpenAI       | `openai`                   | `text-embedding-3-small`                 | `OpenAI`             |
| Voyage       | `voyageai`                 | `voyage-4-lite`                          | `VoyageAIClient`     |
| Cohere       | `cohere-ai`                | `embed-v4.0`                             | `CohereClientV2`     |
| Jina         | Built into `react-ai-chat` | `jina-embeddings-v3`                     | `createJinaClient()` |
| Hugging Face | `@huggingface/inference`   | `sentence-transformers/all-MiniLM-L6-v2` | `InferenceClient`    |

The SDK packages are optional peer dependencies. Install only the provider SDKs you use. Jina does not require an additional SDK.

## Using a provider with the CLI

The provider can be selected when generating an embedding index with the `react-ai-chat` CLI.

Google:

```bash
npx react-ai-chat --google
```

OpenAI:

```bash
npx react-ai-chat --openai
```

Voyage:

```bash
npx react-ai-chat --voyage
```

Cohere:

```bash
npx react-ai-chat --cohere
```

Jina:

```bash
npx react-ai-chat --jina
```

Hugging Face:

```bash
npx react-ai-chat --huggingface
```

The CLI creates embeddings for your content and writes them to the generated embedding index.

See [CLI](/docs/guides/cli) for the complete setup.

## Using a provider with RAG

The provider is passed to `createChatRoute()` when you enable RAG.

```tsx
import { createChatRoute } from "react-ai-chat/server";

export const POST = createChatRoute({
  model,
  rag: {
    index,
    provider,
    topK: 3,
  },
});
```

The provider generates an embedding for the user's question.

`react-ai-chat` compares that embedding against the vectors stored in the index and retrieves the most relevant chunks.

See [RAG](/docs/guides/rag) for the complete workflow.

## Embedding provider interface

All provider wrappers implement the same `EmbeddingProvider` interface:

```ts
interface EmbeddingProvider {
  name: string;
  model: string;

  embed(
    text: string,
    type?: "document" | "query"
  ): Promise<number[]>;
}
```

The `type` parameter identifies whether the text is being embedded as a document or as a query.

This common interface allows the RAG system to work with different providers without changing the retrieval code.

## Provider functions

The provider functions are available from the server entry:

```tsx
import {
  googleEmbedding,
  openAIEmbedding,
  voyageEmbedding,
  cohereEmbedding,
  createJinaClient,
  jinaEmbedding,
  huggingFaceEmbedding,
} from "react-ai-chat/server";
```

| Provider     | Function                 |
| ------------ | ------------------------ |
| Google       | `googleEmbedding()`      |
| OpenAI       | `openAIEmbedding()`      |
| Voyage       | `voyageEmbedding()`      |
| Cohere       | `cohereEmbedding()`      |
| Jina         | `jinaEmbedding()`        |
| Hugging Face | `huggingFaceEmbedding()` |

Jina additionally exports `createJinaClient()` because its HTTP client is implemented inside `react-ai-chat`.
