# Chatbot

The `<Chatbot />` component provides a complete, ready-to-use chat interface.

```tsx
"use client";

import { Chatbot } from "react-ai-chat";
import "react-ai-chat/style.css";

export function MyChatbot() {
  return <Chatbot apiEndpoint="/api/chat" />;
}
```

The component handles the chatbot UI, message state, input, loading state, theme, and communication with your API route.

If you need complete control over the UI source code, use the [Generated Chatbot](/docs/guides/generated-chatbot) instead.

## Props

### Content

| Prop                  | Type     | Default                                                                     | Description                                 |
| --------------------- | -------- | --------------------------------------------------------------------------- | ------------------------------------------- |
| `title`               | `string` | `"Ask AI Assistant"`                                                        | Title displayed in the chatbot header.      |
| `subtitle`            | `string` | `"Trained on custom project data and experience"`                           | Subtitle displayed below the title.         |
| `triggerText`         | `string` | `"Ask AI"`                                                                  | Text displayed inside the trigger button.   |
| `placeholder`         | `string` | `"Ask a question..."`                                                       | Placeholder displayed in the message input. |
| `emptyStateText`      | `string` | `"👋 Hi! Ask me anything about skills, portfolio projects, or background."` | Text displayed when there are no messages.  |
| `starterPromptsLabel` | `string` | `"Try asking:"`                                                             | Label displayed above starter prompts.      |

### Starter prompts

Use `starterPrompts` to provide suggested questions when the conversation is empty.

```tsx
<Chatbot
  starterPrompts={[
    "What is the main tech stack?",
    "Tell me about key projects.",
    "How can I get started?",
  ]}
/>
```

Type:

```ts
starterPrompts?: string[];
```

Each prompt is rendered as a button. Selecting one sends it as a normal chat message.

An empty array hides the starter prompts:

```tsx
<Chatbot starterPrompts={[]} />
```

### API endpoint

Use `apiEndpoint` to specify the endpoint that receives chat requests.

```tsx
<Chatbot apiEndpoint="/api/chat" />
```

Type:

```ts
apiEndpoint?: string;
```

The default endpoint is:

```text
/api/chat
```

The endpoint should be backed by `createChatRoute()` or another compatible chat API.

See [API Route](/docs/getting-started/api-route).

### Position

Use `position` to control where the chatbot appears.

```tsx
<Chatbot position="bottom-right" />
```

Available values:

```ts
type ChatbotPosition =
  | "bottom-right"
  | "bottom-left"
  | "top-right"
  | "top-left";
```

The default is:

```text
bottom-right
```

### Initial state

Use `initialOpen` to control whether the chatbot starts open.

```tsx
<Chatbot initialOpen />
```

Type:

```ts
initialOpen?: boolean;
```

The default is:

```text
false
```

### Theme mode

Use `themeMode` to control the chatbot's color mode.

```tsx
<Chatbot themeMode="dark" />
```

Available values:

```ts
type ThemeMode = "auto" | "light" | "dark";
```

The default is:

```text
auto
```

With `auto`, the chatbot follows the user's system color preference.

You can combine `themeMode` with custom theme tokens.

See [Customization](/docs/guides/customization).

### Icons

The chatbot accepts custom React nodes for the trigger, send, and close buttons.

#### Trigger icon

```tsx
<Chatbot triggerIcon={<MyTriggerIcon />} />
```

Type:

```ts
triggerIcon?: ReactNode;
```

#### Send icon

```tsx
<Chatbot sendIcon={<MySendIcon />} />
```

Type:

```ts
sendIcon?: ReactNode;
```

#### Close icon

```tsx
<Chatbot closeIcon={<MyCloseIcon />} />
```

Type:

```ts
closeIcon?: ReactNode;
```

You can use your own components or icons from a library such as Lucide.

### Theme

Use `theme` to customize the chatbot's colors.

You can provide flat theme tokens:

```tsx
<Chatbot
  theme={{
    primaryColor: "#18181b",
    primaryForeground: "#ffffff",
    background: "#ffffff",
    foreground: "#18181b",
    mutedBackground: "#f4f4f5",
    mutedForeground: "#71717a",
    borderColor: "#e4e4e7",
  }}
/>
```

#### Theme tokens

| Token               | Description                                                       |
| ------------------- | ----------------------------------------------------------------- |
| `primaryColor`      | Primary color used by the header, trigger, and user messages.     |
| `primaryForeground` | Text and icon color used on primary elements.                     |
| `background`        | Main background color of the chatbot.                             |
| `foreground`        | Main text color.                                                  |
| `mutedBackground`   | Background used for assistant messages, inputs, and prompt chips. |
| `mutedForeground`   | Secondary text color used for subtitles and labels.               |
| `borderColor`       | Border color used by inputs and prompt chips.                     |

Every token is optional.

For example:

```tsx
<Chatbot
  theme={{
    primaryColor: "#2563eb",
    background: "#f8fafc",
  }}
/>
```

Only the specified values are overridden.

#### Light and dark themes

You can provide separate values for light and dark modes.

```tsx
<Chatbot
  theme={{
    light: {
      primaryColor: "#18181b",
      primaryForeground: "#ffffff",
      background: "#ffffff",
      foreground: "#18181b",
    },
    dark: {
      primaryColor: "#fafafa",
      primaryForeground: "#18181b",
      background: "#18181b",
      foreground: "#fafafa",
    },
  }}
/>
```

You can also combine base tokens with light and dark overrides:

```tsx
<Chatbot
  theme={{
    borderColor: "#e4e4e7",
    light: {
      background: "#ffffff",
    },
    dark: {
      background: "#18181b",
      borderColor: "#3f3f46",
    },
  }}
/>
```

The theme works with `themeMode`:

```tsx
<Chatbot
  themeMode="auto"
  theme={{
    light: {
      background: "#ffffff",
    },
    dark: {
      background: "#18181b",
    },
  }}
/>
```

### Custom classes

Use `classNames` to add your own CSS classes to selected chatbot elements.

```tsx
<Chatbot
  classNames={{
    wrapper: "my-chatbot-wrapper",
    trigger: "my-chatbot-trigger",
    window: "my-chatbot-window",
    header: "my-chatbot-header",
  }}
/>
```

Available keys:

| Key       | Applied to               |
| --------- | ------------------------ |
| `wrapper` | Outer chatbot wrapper.   |
| `trigger` | Floating trigger button. |
| `window`  | Chat window.             |
| `header`  | Chat window header.      |

Type:

```ts
classNames?: {
  wrapper?: string;
  trigger?: string;
  window?: string;
  header?: string;
};
```

These classes are added alongside the component's built-in classes, so you can override or extend the default styling from your application.

### Error handling

Use `onError` to receive errors that occur while sending a message.

```tsx
<Chatbot
  onError={(error) => {
    console.error("Chatbot error:", error);
  }}
/>
```

Type:

```ts
onError?: (error: Error) => void;
```

You can use this callback to display your own error UI, log failures, or send errors to your monitoring system.

## Complete example

```tsx
"use client";

import { Chatbot } from "react-ai-chat";
import "react-ai-chat/style.css";

export function MyChatbot() {
  return (
    <Chatbot
      title="Project Assistant"
      subtitle="Ask questions about this project"
      triggerText="Ask AI"
      triggerIcon={<span>💬</span>}
      sendIcon={<span>↑</span>}
      closeIcon={<span>×</span>}
      position="bottom-right"
      initialOpen={false}
      themeMode="auto"
      placeholder="Ask about the project..."
      emptyStateText="👋 What would you like to know?"
      starterPrompts={[
        "What does this project do?",
        "How do I get started?",
        "What technologies does it use?",
      ]}
      starterPromptsLabel="Try asking:"
      apiEndpoint="/api/chat"
      theme={{
        light: {
          primaryColor: "#18181b",
          primaryForeground: "#ffffff",
          background: "#ffffff",
          foreground: "#18181b",
        },
        dark: {
          primaryColor: "#fafafa",
          primaryForeground: "#18181b",
          background: "#18181b",
          foreground: "#fafafa",
        },
      }}
      classNames={{
        wrapper: "my-chatbot",
      }}
      onError={(error) => {
        console.error(error);
      }}
    />
  );
}
```

## When to use `<Chatbot />`

The ready-made component is a good choice when you want a complete chatbot and need configuration through props.

```tsx
<Chatbot title="Project Assistant" themeMode="dark" position="bottom-right" />
```

Use the [Generated Chatbot](/docs/guides/generated-chatbot) when you want to own the UI source code and change the structure of the chatbot itself.

The generated version gives you direct access to the header, messages, input, trigger, and styling files while `react-ai-chat` continues to provide the underlying chatbot state and API communication.
