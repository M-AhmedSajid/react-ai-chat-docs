# ChatbotProvider

`ChatbotProvider` provides the state and actions used by the generated chatbot UI.

It is useful when you want to build your own chatbot interface while keeping `react-ai-chat` responsible for chat state and communication with your API route.

## Import

```tsx id="y6jv3q"
import { ChatbotProvider, useChatbotContext } from "react-ai-chat";
```

## Basic usage

Wrap your chatbot UI with `ChatbotProvider`:

```tsx id="w9h4kc"
<ChatbotProvider>
  <YourChatbot />
</ChatbotProvider>
```

Components inside the provider can then access the chatbot state through `useChatbotContext()`.

```tsx id="j3v7sx"
function YourChatbot() {
  const { messages, input, setInput, handleSubmit, isLoading } =
    useChatbotContext();

  return <div>{/* Your chatbot UI */}</div>;
}
```

## Provider options

`ChatbotProvider` accepts the configuration required by the chatbot state.

The generated chatbot uses the provider internally, so you usually only need to use it directly when building a custom UI.

### `apiEndpoint`

```ts id="s8f2qd"
apiEndpoint?: string
```

The endpoint used for chat requests.

**Default:** `"/api/chat"`

```tsx id="x4m7pk"
<ChatbotProvider apiEndpoint="/api/assistant">
  <YourChatbot />
</ChatbotProvider>
```

## Context

Use `useChatbotContext()` inside a `ChatbotProvider` to access the chatbot state and actions.

```tsx id="v2n9cz"
const {
  messages,
  input,
  setInput,
  handleSubmit,
  isLoading,
  isOpen,
  setIsOpen,
} = useChatbotContext();
```

### `messages`

The current conversation messages.

```ts id="j7c4mx"
messages;
```

Use this value to render the conversation.

```tsx id="q9s2vr"
{
  messages.map((message) => (
    <div key={message.id}>
      {message.role}: {message.content}
    </div>
  ));
}
```

### `input`

The current value of the message input.

```ts id="n5d8wp"
input: string;
```

### `setInput`

Updates the message input.

```ts id="a3f6ky"
setInput: (value: string) => void
```

Example:

```tsx id="c8m2zr"
<input value={input} onChange={(event) => setInput(event.target.value)} />
```

### `handleSubmit`

Submits the current message.

```ts id="f4q8nb"
handleSubmit: () => void
```

Example:

```tsx id="u7x1mc"
<button onClick={handleSubmit}>Send</button>
```

### `isLoading`

Indicates whether the chatbot is waiting for a response.

```ts id="e6r3pv"
isLoading: boolean;
```

Use it to disable controls or display a loading indicator:

```tsx id="k2z5wd"
{
  isLoading && <span>Thinking...</span>;
}
```

### `isOpen`

Indicates whether the chatbot UI is currently open.

```ts id="p8v4qs"
isOpen: boolean;
```

### `setIsOpen`

Controls the open state.

```ts id="m6x9rt"
setIsOpen: (open: boolean) => void
```

Example:

```tsx id="z3c7hf"
<button onClick={() => setIsOpen(true)}>Open chat</button>
```

## Custom chatbot example

You can combine the provider and context to build your own interface:

```tsx id="r5k8nd"
import { ChatbotProvider, useChatbotContext } from "react-ai-chat";

function CustomChatbot() {
  const { messages, input, setInput, handleSubmit, isLoading } =
    useChatbotContext();

  return (
    <div>
      <div>
        {messages.map((message) => (
          <div key={message.id}>
            {message.role}: {message.content}
          </div>
        ))}
      </div>

      <form
        onSubmit={(event) => {
          event.preventDefault();
          handleSubmit();
        }}
      >
        <input
          value={input}
          onChange={(event) => setInput(event.target.value)}
          placeholder="Ask something..."
        />

        <button type="submit" disabled={isLoading || !input.trim()}>
          Send
        </button>
      </form>
    </div>
  );
}

export default function App() {
  return (
    <ChatbotProvider apiEndpoint="/api/chat">
      <CustomChatbot />
    </ChatbotProvider>
  );
}
```

## Provider vs ready-made Chatbot

Use `<Chatbot />` when you want the complete built-in interface.

Use `ChatbotProvider` when you want to build the interface yourself while using the package's chat state and request handling.

The generated chatbot uses this approach internally.

## Important

`useChatbotContext()` must be called from a component rendered inside `ChatbotProvider`.

This will cause an error:

```tsx id="y5c2jx"
function MyComponent() {
  const context = useChatbotContext();

  return <div />;
}
```

when `MyComponent` is rendered without a provider.

Wrap it with:

```tsx id="v8n4kc"
<ChatbotProvider>
  <MyComponent />
</ChatbotProvider>
```
