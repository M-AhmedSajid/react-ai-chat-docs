# Installation

Install `react-ai-chat` in your React application and choose how you want to build your chatbot.

<Callout type="info">
  <strong>Prerequisites</strong>

  <ul>
    <li>Node.js 18 or later</li>
    <li>React 18 or React 19</li>
    <li>React DOM 18 or React DOM 19</li>
    <li>Basic familiarity with React and TypeScript</li>
  </ul>
</Callout>

## Install react-ai-chat

<Steps>
  <Step>
    ### Install the package

    ### Import the stylesheet

If you are using the ready-made `<Chatbot />` component, import the package stylesheet once in your application's global stylesheet entry.

```tsx

```

The generated chatbot has its own `chatbot.css`, so you do not need the package stylesheet when using the generated UI.

  </Step>
</Steps>

## AI model provider

`react-ai-chat` uses the Vercel AI SDK for the server-side model connection.

The `ai` package is included by `react-ai-chat`. You only need to install the provider package for the model you want to use.

For example, with Google:

```bash
npm install @ai-sdk/google
```

Then create your model in your API route:

```tsx
import { google } from "@ai-sdk/google";
import { createChatRoute } from "react-ai-chat/server";

export const POST = createChatRoute({
  model: google("your-model"),
});
```

The exact provider package depends on the AI model provider you choose.

## Environment variables

Set the API key required by your selected provider.

For example, Google AI SDK:

```text
GOOGLE_GENERATIVE_AI_API_KEY=your_api_key_here
```

For RAG, use the environment variable required by the embedding provider.

Keep API keys on the server. Do not expose them in client-side code.

## Choose your chatbot setup

You have two ways to build the UI.

### Ready-made chatbot

Use `<Chatbot />` when you want a complete chatbot component with built-in UI.

```tsx
import { Chatbot } from "react-ai-chat";
import "react-ai-chat/style.css";

export default function App() {
  return <Chatbot />;
}
```

Continue with [Quick Start](/docs/getting-started/quick-start).

### Generated chatbot

Use the CLI when you want the chatbot UI source code inside your project.

```bash
npx react-ai-chat init
```

The CLI generates editable React components and CSS that you can modify directly.

Continue with [Generated Chatbot](/docs/guides/generated-chatbot).

## Server setup

Create an API endpoint with `createChatRoute()` and provide an AI SDK language model.

```tsx
import { createChatRoute } from "react-ai-chat/server";
import { google } from "@ai-sdk/google";

export const POST = createChatRoute({
  model: google("your-model"),
});
```

Continue with [API Route](/docs/getting-started/api-route) to configure the server endpoint.
