# Quick Start

Build a working AI chatbot with `react-ai-chat` in a few steps.

This guide uses the ready-made `<Chatbot />` component. If you want the chatbot UI source inside your project, see [Generated Chatbot](/docs/guides/generated-chatbot).

## 1. Install the dependencies

Install `react-ai-chat` and the AI SDK provider for the model you want to use.

```bash
npm install react-ai-chat @ai-sdk/google
```

`ai` is already included as a dependency of `react-ai-chat`, so you do not need to install it separately.

## 2. Add your API key

Create or update your environment file:

```text
GOOGLE_GENERATIVE_AI_API_KEY=your_api_key_here
```

Keep your API key on the server. Do not expose it through client-side environment variables.

## 3. Create the API route

Create a route for your chatbot.

For a Next.js App Router application, create:

```text
app/
└── api/
    └── chat/
        └── route.ts
```

Add:

```tsx
import { google } from "@ai-sdk/google";
import { createChatRoute } from "react-ai-chat/server";

export const POST = createChatRoute({
  model: google("your-model"),
});
```

`createChatRoute()` handles the incoming messages and streams the model response back to the chatbot.

Your route can use any AI SDK-compatible language model.

## 4. Add the chatbot

Import `Chatbot` and the package stylesheet into your application.

```tsx
import { Chatbot } from "react-ai-chat";
import "react-ai-chat/style.css";

export default function Page() {
  return <Chatbot />;
}
```

The chatbot sends requests to:

```text
/api/chat
```

which matches the route created in the previous step.

## 5. Configure the chatbot

You can customize the chatbot directly through its props.

For example:

```tsx
<Chatbot
  title="My AI Assistant"
  subtitle="Ask me anything"
  placeholder="Type your question..."
  position="bottom-right"
  initialOpen={true}
/>
```

You can also configure starter prompts, icons, theme mode, custom classes, theme tokens, and error handling.

See [Chatbot UI](/docs/getting-started/chatbot-ui) for the complete list of options.

## How it works

The basic request flow looks like this:

```text
User
  ↓
<Chatbot />
  ↓
POST /api/chat
  ↓
createChatRoute()
  ↓
AI SDK model
  ↓
Streaming response
  ↓
<Chatbot />
```

The browser only communicates with your API route. Your model provider credentials stay on the server.

## Add your own knowledge

The basic chatbot can answer using the model's existing knowledge.

To make it answer questions from your own documentation, files, or other content, add RAG.

The CLI can create an embedding index from your documents:

```bash
npx react-ai-chat
```

The CLI lets you choose the embedding provider, model, dimensions, fallback model, source documents, and output path interactively.

See [RAG](/docs/guides/rag) for the complete setup.

## Generate an editable chatbot

If you want full control over the chatbot UI, generate the components into your project:

```bash
npx react-ai-chat init
```

This creates editable React components and CSS.

```text
chatbot/
├── chatbot.tsx
├── chatbot-header.tsx
├── chatbot-messages.tsx
├── chatbot-input.tsx
└── chatbot.css
```

The generated components use `ChatbotProvider` and `useChatbotContext` from `react-ai-chat`.

See [Generated Chatbot](/docs/guides/generated-chatbot) to learn how it works.
