# Chatbot UI

`react-ai-chat` provides a ready-to-use chatbot UI that you can configure through props or generate the chatbot when you need more control.

## Basic usage

The simplest way to add the chatbot is to use the `Chatbot` component.

```tsx
"use client";

import { Chatbot } from "react-ai-chat";
import "react-ai-chat/style.css";

export function MyChatbot() {
  return <Chatbot apiEndpoint="/api/chat" />;
}
```

The `Chatbot` component handles the chat interface and communicates with the API endpoint you provide.

The endpoint should be created on your server with [`createChatRoute()`](/docs/getting-started/api-route).

## Configure the chatbot

You can customize the chatbot using props.

```tsx
"use client";

import { Chatbot } from "react-ai-chat";
import "react-ai-chat/style.css";

export function MyChatbot() {
  return (
    <Chatbot
      title="AI Assistant"
      subtitle="Ask me anything"
      triggerText="Chat with AI"
      position="bottom-right"
      initialOpen={false}
      themeMode="auto"
      placeholder="Ask a question..."
      starterPrompts={[
        "What can you help me with?",
        "Tell me about this website",
      ]}
      emptyStateText="How can I help you?"
      starterPromptsLabel="Try asking"
      apiEndpoint="/api/chat"
    />
  );
}
```

### Position

Use the `position` prop to control where the chatbot appears.

```tsx
<Chatbot position="bottom-right" />
```

Available positions:

```text
bottom-right
bottom-left
top-right
top-left
```

The default position is `bottom-right`.

### Initial state

Use `initialOpen` to control whether the chatbot starts open.

```tsx
<Chatbot initialOpen />
```

The default value is `false`.

### API endpoint

Use `apiEndpoint` to specify the server endpoint that handles chat requests.

```tsx
<Chatbot apiEndpoint="/api/chat" />
```

If you use the default `/api/chat` endpoint, you can omit this prop.

```tsx
<Chatbot />
```

See [API Route](/docs/getting-started/api-route) to learn how to create the endpoint.

## Empty state and starter prompts

When the conversation has no messages, you can show custom text and starter prompts.

```tsx
<Chatbot
  emptyStateText="What would you like to know?"
  starterPrompts={[
    "What can you help me with?",
    "Explain this project",
    "Show me an example",
  ]}
  starterPromptsLabel="Try one of these"
/>
```

Use:

* `emptyStateText` to change the empty state message.
* `starterPrompts` to provide suggested questions.
* `starterPromptsLabel` to change the label shown above the prompts.

Starter prompts are sent as normal chat messages when selected.

## Custom text

You can customize the visible text used by the chatbot.

```tsx
<Chatbot
  title="Project Assistant"
  subtitle="Ask questions about my project"
  triggerText="Open assistant"
  placeholder="Ask about the project..."
/>
```

Available text props include:

| Prop                  | Description                              |
| --------------------- | ---------------------------------------- |
| `title`               | Title shown in the chatbot header        |
| `subtitle`            | Subtitle shown below the title           |
| `triggerText`         | Text shown inside the collapsed trigger  |
| `placeholder`         | Placeholder shown inside the input       |
| `emptyStateText`      | Message shown when there are no messages |
| `starterPromptsLabel` | Label shown above starter prompts        |

## Custom icons

The trigger, send, and close buttons accept custom React nodes.

```tsx
import { Chatbot } from "react-ai-chat";
import { MessageCircle, Send, X } from "lucide-react";
import "react-ai-chat/style.css";

export function MyChatbot() {
  return (
    <Chatbot
      triggerIcon={<MessageCircle />}
      sendIcon={<Send />}
      closeIcon={<X />}
    />
  );
}
```

You can use your own React elements or an icon library.

## Theme mode

Use `themeMode` to control the chatbot's color mode.

```tsx
<Chatbot themeMode="auto" />
```

Available values:

```text
auto
light
dark
```

`auto` follows the user's system color preference.

```tsx
<Chatbot themeMode="light" />
```

```tsx
<Chatbot themeMode="dark" />
```

For custom colors and light/dark theme tokens, see [Customization](/docs/guides/customization).

## Custom classes

You can add your own classes to the main chatbot elements.

```tsx
<Chatbot
  classNames={{
    wrapper: "my-chatbot-wrapper",
    trigger: "my-chatbot-trigger",
    window: "my-chatbot-window",
    header: "my-chatbot-header",
  }}
/>
```

This lets you add application-specific CSS without changing the package source.

## Generate the chatbot

The CLI can generate a customizable chatbot directly inside your project.

```bash
npx react-ai-chat init
```

The generated implementation includes separate files for the chatbot, header, messages, input, and CSS.

```text
chatbot.tsx
chatbot-header.tsx
chatbot-messages.tsx
chatbot-input.tsx
chatbot.css
```

You can then modify these files like regular React components.

You can also generate JSX instead of TSX:

```bash
npx react-ai-chat init --jsx
```

See [Generated Chatbot](/docs/guides/generated-chatbot) for the complete CLI workflow.

## Error handling

Use `onError` to handle errors reported by the chat request.

```tsx
<Chatbot
  onError={(error) => {
    console.error("Chatbot error:", error);
  }}
/>
```

This can be useful for displaying your own error notification or logging errors in your application.

## Scroll behavior

When the chatbot is open, `react-ai-chat` manages the document scroll state so the chatbot can behave correctly on smaller screens.

You do not need to add separate scroll-lock logic for the standard chatbot component.
