# API Route

`react-ai-chat` provides `createChatRoute()` for creating the server endpoint used by your chatbot.

It accepts an AI SDK-compatible language model, handles incoming messages, and streams the model response back to the client.

## Basic setup

For a Next.js App Router application, create:

```text id="qj7x9m"
app/
└── api/
    └── chat/
        └── route.ts
```

Then:

```tsx id="u2j6k8"
import { google } from "@ai-sdk/google";
import { createChatRoute } from "react-ai-chat/server";

export const POST = createChatRoute({
  model: google("your-model"),
});
```

Your chatbot can now send requests to `/api/chat`.

## How the route works

When a request reaches your route, `createChatRoute()`:

1. Reads the messages from the request body.
2. Keeps the most recent messages according to `maxMessages`.
3. Optionally retrieves relevant RAG context.
4. Builds the final system prompt.
5. Converts the messages for the AI SDK.
6. Streams the model response back to the client.

The response uses the AI SDK UI message stream format.

## Configuration

`createChatRoute()` accepts a `ChatRouteOptions` object.

### `model`

The AI SDK language model used to generate responses.

```tsx id="9efz4c"
import { google } from "@ai-sdk/google";
import { createChatRoute } from "react-ai-chat/server";

export const POST = createChatRoute({
  model: google("your-model"),
});
```

This is required.

The model can come from any provider supported by the AI SDK.

### `systemPrompt`

Controls the system instructions sent to the model.

```tsx id="p3u0yd"
export const POST = createChatRoute({
  model: google("your-model"),
  systemPrompt: "You are a helpful assistant for my documentation.",
});
```

The default prompt is:

```text id="v6f4ps"
You are a helpful AI chatbot. Have natural, conversational interactions with the user. Answer questions clearly and accurately. Use the context provided to you when it is relevant to the user's question.
```

When RAG context is available, the retrieved context is added to this system prompt.

### `maxMessages`

Controls how many of the most recent messages are sent through the route.

```tsx id="5k4zpu"
export const POST = createChatRoute({
  model: google("your-model"),
  maxMessages: 10,
});
```

The default is `6`.

The route keeps the last `maxMessages` messages:

```text id="k7r4tq"
All messages
    ↓
Keep latest maxMessages
    ↓
Convert to model messages
    ↓
Send to model
```

Keeping the history limited can reduce the amount of conversation data sent to the model.

## RAG

You can optionally connect an embedding index to the route.

```tsx id="9r4q6c"
import { google } from "@ai-sdk/google";
import { createChatRoute } from "react-ai-chat/server";
import embeddings from "./embeddings.json";

export const POST = createChatRoute({
  model: google("your-model"),
  rag: {
    index: embeddings,
    provider: yourEmbeddingProvider,
  },
});
```

When RAG is enabled, the route uses the latest user message as the search query.

The default number of retrieved chunks is `3`.

You can change it with `topK`:

```tsx id="d0z8tj"
export const POST = createChatRoute({
  model: google("your-model"),
  rag: {
    index: embeddings,
    provider: yourEmbeddingProvider,
    topK: 5,
  },
});
```

The retrieval flow is:

```text id="t3e4y9"
Latest user message
       ↓
Generate query embedding
       ↓
Compare with embedding index
       ↓
Select topK chunks
       ↓
Add relevant context to system prompt
       ↓
Generate response
```

If RAG retrieval fails, the error is logged and the request continues without the retrieved context.

## RAG provider

The provider used for retrieval must match the provider and model configuration stored in the embedding index.

For example:

```tsx id="g9h3w1"
import { googleEmbedding } from "react-ai-chat/server";

export const POST = createChatRoute({
  model: google("your-model"),
  rag: {
    index: embeddings,
    provider: googleEmbedding({
      apiKey: process.env.GEMINI_API_KEY,
      model: "your-embedding-model",
    }),
  },
});
```

Use the provider that matches the embedding index you generated.

See [Providers](/docs/api/providers) for the supported embedding providers.

## Custom system prompts with RAG

When relevant context is found, `react-ai-chat` adds it to your system prompt.

Conceptually, the final prompt becomes:

```text id="7x6b3p"
Your system prompt

Here is relevant context retrieved from the application's knowledge base.
Use it when relevant to the user's question.

=== RELEVANT CONTEXT ===
Retrieved content
=======================
```

The model receives the context as part of the system instructions.

## Message handling

The route expects the request body to contain a `messages` array.

```json id="m4xq2v"
{
  "messages": [
    {
      "role": "user",
      "parts": [
        {
          "type": "text",
          "text": "What is React?"
        }
      ]
    }
  ]
}
```

The route supports text content represented by the message structure used by the AI SDK UI message format.

Only the most recent `maxMessages` messages are processed.

## Streaming

Responses are streamed back to the client using the AI SDK UI message stream.

You do not need to manually create a `ReadableStream` or implement response chunking.

```tsx id="c5n8yx"
export const POST = createChatRoute({
  model: google("your-model"),
});
```

The returned route handler takes care of the streaming response.

## Error handling

Errors from the chat route are represented using `ChatbotError`.

Model-related errors can be reported as invalid model errors.

Other execution errors are reported as chat route execution failures.

RAG retrieval errors are handled separately. They are logged and the model can continue without retrieved context.

## Complete example

```tsx id="m3k7az"
import { google } from "@ai-sdk/google";
import { createChatRoute } from "react-ai-chat/server";

export const POST = createChatRoute({
  model: google("your-model"),
  systemPrompt: "You are a helpful assistant for my documentation website.",
  maxMessages: 8,
});
```

Your client can then use the matching endpoint:

```tsx id="r8c2wv"
import { Chatbot } from "react-ai-chat";
import "react-ai-chat/style.css";

export default function Page() {
  return <Chatbot apiEndpoint="/api/chat" />;
}
```
