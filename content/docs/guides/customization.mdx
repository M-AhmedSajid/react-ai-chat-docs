## Customization

`react-ai-chat` gives you two levels of customization.

Use the ready-made `<Chatbot />` when you want to configure the existing interface through props.

Use the generated chatbot when you want to change the UI structure and own the source code.

```text
<Chatbot />
    ↓
Props, theme, icons, classes
    ↓
Need more control?
    ↓
Generated chatbot
    ↓
Edit the generated source directly
```

### Customize content

You can change the text displayed throughout the chatbot:

```tsx
<Chatbot
  title="Project Assistant"
  subtitle="Ask questions about this project"
  triggerText="Ask AI"
  placeholder="Ask a question..."
  emptyStateText="How can I help?"
  starterPromptsLabel="Try asking:"
/>
```

You can also provide your own starter prompts:

```tsx
<Chatbot
  starterPrompts={[
    "What does this project do?",
    "How do I get started?",
    "Show me an example",
  ]}
/>
```

Starter prompts are displayed when the conversation has no messages. Selecting one sends it as a normal chat message.

Set `starterPrompts` to an empty array to hide them:

```tsx
<Chatbot starterPrompts={[]} />
```

See [`<Chatbot />`](/docs/api/chatbot) for all available content props.

### Position

Control where the chatbot appears:

```tsx
<Chatbot position="bottom-right" />
```

Available positions:

```ts
type ChatbotPosition =
  | "bottom-right"
  | "bottom-left"
  | "top-right"
  | "top-left";
```

The default is `bottom-right`.

### Initial state

Open the chatbot automatically when it mounts:

```tsx
<Chatbot initialOpen />
```

The default value is `false`.

### Theme mode

Choose how the chatbot handles light and dark themes:

```tsx
<Chatbot themeMode="dark" />
```

Available values:

```ts
type ThemeMode = "auto" | "light" | "dark";
```

`auto` follows the user's system color preference.

```tsx
<Chatbot themeMode="auto" />
```

### Theme colors

Use the `theme` prop to customize the chatbot's colors:

```tsx
<Chatbot
  theme={{
    primaryColor: "#18181b",
    primaryForeground: "#ffffff",
    background: "#ffffff",
    foreground: "#18181b",
    mutedBackground: "#f4f4f5",
    mutedForeground: "#71717a",
    borderColor: "#e4e4e7",
  }}
/>
```

#### Theme tokens

| Token               | Description                                                       |
| ------------------- | ----------------------------------------------------------------- |
| `primaryColor`      | Primary color used by the header, trigger, and user messages.     |
| `primaryForeground` | Text and icon color used on primary elements.                     |
| `background`        | Main background color of the chatbot.                             |
| `foreground`        | Main text color.                                                  |
| `mutedBackground`   | Background used for assistant messages, inputs, and prompt chips. |
| `mutedForeground`   | Secondary text color used for subtitles and labels.               |
| `borderColor`       | Border color used by inputs and prompt chips.                     |

Every token is optional.

For example:

```tsx
<Chatbot
  theme={{
    primaryColor: "#2563eb",
    background: "#f8fafc",
  }}
/>
```

Only the specified values are overridden.

### Light and dark themes

You can provide separate values for light and dark modes:

```tsx
<Chatbot
  themeMode="auto"
  theme={{
    light: {
      primaryColor: "#18181b",
      primaryForeground: "#ffffff",
      background: "#ffffff",
      foreground: "#18181b",
    },
    dark: {
      primaryColor: "#fafafa",
      primaryForeground: "#18181b",
      background: "#18181b",
      foreground: "#fafafa",
    },
  }}
/>
```

You can combine base tokens with light and dark overrides:

```tsx
<Chatbot
  theme={{
    borderColor: "#e4e4e7",
    light: {
      background: "#ffffff",
    },
    dark: {
      background: "#18181b",
      borderColor: "#3f3f46",
    },
  }}
/>
```

This lets you define shared values while overriding individual tokens for each mode.

### Custom icons

You can replace the default icons with your own React nodes.

#### Trigger icon

```tsx
<Chatbot triggerIcon={<MyTriggerIcon />} />
```

#### Send icon

```tsx
<Chatbot sendIcon={<MySendIcon />} />
```

#### Close icon

```tsx
<Chatbot closeIcon={<MyCloseIcon />} />
```

You can use your own components or icons from a library such as Lucide.

### Custom classes

Use `classNames` when you need to add application-specific CSS classes to the existing chatbot elements:

```tsx
<Chatbot
  classNames={{
    wrapper: "my-chatbot-wrapper",
    trigger: "my-chatbot-trigger",
    window: "my-chatbot-window",
    header: "my-chatbot-header",
  }}
/>
```

Available keys:

| Key       | Applied to               |
| --------- | ------------------------ |
| `wrapper` | Outer chatbot wrapper.   |
| `trigger` | Floating trigger button. |
| `window`  | Chat window.             |
| `header`  | Chat window header.      |

These classes are added alongside the chatbot's built-in classes.

For example:

```tsx
<Chatbot
  classNames={{
    wrapper: "project-chatbot",
  }}
/>
```

```css
.project-chatbot {
  font-family: Inter, sans-serif;
}
```

This approach works well when you want to style the existing interface without changing its structure.

### Custom error handling

Use `onError` to handle errors from the chatbot:

```tsx
<Chatbot
  onError={(error) => {
    console.error("Chatbot error:", error);
  }}
/>
```

You can use this callback for your application's error handling, logging, or monitoring.

### Custom API endpoint

The chatbot can connect to a custom endpoint:

```tsx
<Chatbot apiEndpoint="/api/assistant" />
```

The default endpoint is:

```text
/api/chat
```

The endpoint can use `createChatRoute()`:

```tsx
import { createChatRoute } from "react-ai-chat/server";

export const POST = createChatRoute({
  model,
});
```

See [API Route](/docs/getting-started/api-route).

## Full customization example

Here is a chatbot using several customization options together:

```tsx
"use client";

import { Chatbot } from "react-ai-chat";
import "react-ai-chat/style.css";

export function ProjectAssistant() {
  return (
    <Chatbot
      title="Project Assistant"
      subtitle="Ask questions about this project"
      triggerText="Ask AI"
      placeholder="What would you like to know?"
      emptyStateText="Ask me about the project"
      starterPrompts={[
        "What does this project do?",
        "How do I install it?",
        "Show me an example",
      ]}
      starterPromptsLabel="Try asking:"
      position="bottom-right"
      themeMode="auto"
      triggerIcon={<span>💬</span>}
      theme={{
        light: {
          primaryColor: "#18181b",
          primaryForeground: "#ffffff",
          background: "#ffffff",
          foreground: "#18181b",
        },
        dark: {
          primaryColor: "#fafafa",
          primaryForeground: "#18181b",
          background: "#18181b",
          foreground: "#fafafa",
        },
      }}
      classNames={{
        wrapper: "project-chatbot",
      }}
      apiEndpoint="/api/chat"
      onError={(error) => {
        console.error("Chatbot error:", error);
      }}
    />
  );
}
```

## When props are enough

Use `<Chatbot />` when your changes fit within its existing API.

This covers:

- Text and starter prompts
- Position
- Initial open state
- Light and dark themes
- Theme colors
- Trigger, send, and close icons
- CSS classes
- API endpoint
- Error handling

The ready-made component keeps the UI implementation inside the package while letting you configure its supported options.

See [`<Chatbot />`](/docs/api/chatbot) for the complete prop reference.

## When you need full UI control

Use the generated chatbot when you want to change the structure of the interface itself.

Generate it with:

```bash
npx react-ai-chat init
```

The CLI creates editable source files:

```text
chatbot/
├── chatbot.tsx
├── chatbot-header.tsx
├── chatbot-messages.tsx
├── chatbot-input.tsx
└── chatbot.css
```

You own these files and can change their markup and styling directly.

The generated UI uses `ChatbotProvider` and `useChatbotContext` from `react-ai-chat` to access the chatbot state and actions.

For example:

```tsx
import { useChatbotContext } from "react-ai-chat";

export function CustomInput() {
  const { input, setInput, handleSubmit, isLoading } = useChatbotContext();

  return (
    <form onSubmit={handleSubmit}>
      <input
        value={input}
        onChange={(event) => setInput(event.target.value)}
        disabled={isLoading}
      />

      <button type="submit" disabled={isLoading || !input.trim()}>
        Send
      </button>
    </form>
  );
}
```

This is the right approach when you want to build a chatbot UI that matches your application's own design system.

See [Generated Chatbot](/docs/guides/generated-chatbot).
