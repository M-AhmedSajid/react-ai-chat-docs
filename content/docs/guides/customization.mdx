# Customization

The ready-made `<Chatbot />` component provides props for changing its content, position, icons, classes, theme, and behavior.

For deeper control over the component structure, use the generated chatbot. See [Generated Chatbot](/docs/guides/generated-chatbot).

## Text

Customize the text displayed throughout the chatbot.

```tsx
<Chatbot
  title="Support Assistant"
  subtitle="We're here to help"
  triggerText="Chat with support"
  emptyStateText="What can we help you with?"
  placeholder="Type your question..."
  starterPromptsLabel="Popular questions"
/>
```

### Available text props

| Prop                  | Purpose                                   |
| --------------------- | ----------------------------------------- |
| `title`               | Chatbot header title                      |
| `subtitle`            | Chatbot header subtitle                   |
| `triggerText`         | Text displayed on the chat trigger        |
| `emptyStateText`      | Text shown when the conversation is empty |
| `placeholder`         | Input placeholder                         |
| `starterPromptsLabel` | Label displayed above starter prompts     |

## Starter prompts

Add predefined questions that users can select from.

```tsx
<Chatbot
  starterPrompts={[
    "What can you help me with?",
    "How does this work?",
    "Tell me about your services",
  ]}
/>
```

Starter prompts are displayed when the conversation has no messages.

## Position

Choose where the chatbot is placed.

```tsx
<Chatbot position="bottom-right" />
```

Supported values:

```text
bottom-right
bottom-left
top-right
top-left
```

The default is `bottom-right`.

## Custom icons

The chatbot accepts React nodes for its main icons.

```tsx
<Chatbot
  triggerIcon={<ChatIcon />}
  sendIcon={<SendIcon />}
  closeIcon={<CloseIcon />}
/>
```

This lets you use an icon library or your own React components.

## Custom CSS classes

Use `classNames` to provide custom classes for chatbot elements.

```tsx
<Chatbot
  classNames={{
    wrapper: "my-chatbot",
    trigger: "my-trigger",
    window: "my-window",
    header: "my-header",
  }}
/>
```

The available keys are:

| Key       | Purpose              |
| --------- | -------------------- |
| `wrapper` | Root chatbot wrapper |
| `trigger` | Chat trigger button  |
| `window`  | Chat window          |
| `header`  | Chat window header   |

This approach is useful when you want to keep the component structure while changing its styling.

## Theme mode

Control whether the chatbot uses automatic, light, or dark mode.

```tsx
<Chatbot themeMode="light" />
```

```tsx
<Chatbot themeMode="dark" />
```

```tsx
<Chatbot themeMode="auto" />
```

With `auto`, the chatbot follows the user's system color preference.

## Theme tokens

For more control over the appearance, pass a `theme` object.

```tsx
<Chatbot
  theme={{
    primaryColor: "#2563eb",
    primaryForeground: "#ffffff",
    background: "#ffffff",
    foreground: "#111827",
    mutedBackground: "#f3f4f6",
    mutedForeground: "#6b7280",
    borderColor: "#e5e7eb",
  }}
/>
```

The available theme tokens are:

| Token               | Purpose                              |
| ------------------- | ------------------------------------ |
| `primaryColor`      | Primary accent color                 |
| `primaryForeground` | Text color on primary elements       |
| `background`        | Main chatbot background              |
| `foreground`        | Main text color                      |
| `mutedBackground`   | Background for secondary UI elements |
| `mutedForeground`   | Secondary text color                 |
| `borderColor`       | Border color                         |

You can also provide separate light and dark overrides:

```tsx
<Chatbot
  theme={{
    primaryColor: "#7c3aed",
    light: {
      background: "#ffffff",
      foreground: "#18181b",
    },
    dark: {
      background: "#18181b",
      foreground: "#fafafa",
    },
  }}
/>
```

See [Theming](/docs/guides/theming) for the complete theme configuration.

## API endpoint

The chatbot uses `/api/chat` by default.

Set `apiEndpoint` when your server route uses another path.

```tsx
<Chatbot apiEndpoint="/api/assistant" />
```

Your server must expose a `POST` handler at the same endpoint.

## Initial state

Use `initialOpen` to decide whether the chatbot is open when it first renders.

```tsx
<Chatbot initialOpen />
```

The default is `false`.

## Error handling

Use `onError` to respond to errors from the chatbot.

```tsx
<Chatbot
  onError={(error) => {
    console.error("Chatbot error:", error);
  }}
/>
```

You can use this callback to connect the chatbot to your application's error reporting or custom UI.

See [Errors](/docs/api/errors) for the available error types and codes.

## Customizing the generated UI

The props above are useful when the ready-made component gives you enough control.

If you need to change the actual React structure, generate the chatbot instead:

```bash
npx react-ai-chat init --help
```

Use the available `init` flags to choose how the generated chatbot is created for your project.

The generated UI is editable source code. You can change its markup, message rendering, input behavior, and styles directly.

The generated UI uses:

- `ChatbotProvider`
- `useChatbotContext`

from `react-ai-chat`.

This gives you control over the component structure while keeping the package's chat state and request handling.

See [Generated Chatbot](/docs/guides/generated-chatbot).

## Complete example

```tsx
import { Chatbot } from "react-ai-chat";
import "react-ai-chat/style.css";

export default function App() {
  return (
    <Chatbot
      title="Ahmed's Assistant"
      subtitle="Ask me anything"
      triggerText="Chat"
      position="bottom-right"
      initialOpen={false}
      placeholder="Ask a question..."
      emptyStateText="How can I help?"
      starterPrompts={[
        "What can you help me with?",
        "Tell me about this project",
      ]}
      starterPromptsLabel="Try asking"
      themeMode="auto"
      apiEndpoint="/api/chat"
      onError={(error) => {
        console.error(error);
      }}
    />
  );
}
```

## Choosing the right approach

Use the ready-made `<Chatbot />` when you want to configure the existing interface through props.

Use the generated chatbot when your application needs changes to the component structure, message rendering, input behavior, or CSS.
