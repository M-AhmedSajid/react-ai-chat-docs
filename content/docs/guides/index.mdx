## Choose a guide

### Customize the chatbot

Change the chatbot's appearance and behavior to fit your application.

Start with [Customization](/docs/guides/customization) to learn about the available customization options.

### Add your own knowledge

Use RAG when your chatbot needs to answer questions using your own documentation, business content, portfolio data, or other sources.

See [RAG](/docs/guides/rag) to learn how retrieval works and how to configure it.

### Match your design

Use the theme system to match the chatbot with your application's existing design.

See [Theming](/docs/guides/theming) for theme tokens, light and dark modes, and CSS variables.

### Understand the generated UI

The ready-made `Chatbot` component is built using the same provider and context APIs available to you.

Read [Generated Chatbot](/docs/guides/generated-chatbot) to understand how the pieces fit together.

### Generate embeddings

The CLI can process your content and generate an embedding index for RAG.

See [CLI](/docs/guides/cli) for the available commands and embedding providers.

## When to use these guides

Use the guides when you want to move beyond the basic chatbot setup.

```text
Basic chatbot
      ↓
Customize the UI
      ↓
Add your own theme
      ↓
Connect your content with RAG
      ↓
Generate and maintain embeddings
```

You can work through the guides independently based on what your application needs.
