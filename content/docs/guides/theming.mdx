# Theming

`react-ai-chat` lets you customize the chatbot's appearance through the `theme` and `themeMode` props.

You can use the built-in light and dark modes or provide your own theme tokens.

## Theme mode

Set `themeMode` to control which theme the chatbot uses.

```tsx id="v2k8mx"
<Chatbot themeMode="light" />
```

```tsx id="q6p3zr"
<Chatbot themeMode="dark" />
```

```tsx id="n8w4yc"
<Chatbot themeMode="auto" />
```

The available values are:

| Value   | Behavior                            |
| ------- | ----------------------------------- |
| `light` | Always use the light theme          |
| `dark`  | Always use the dark theme           |
| `auto`  | Follow the user's system preference |

The default is `auto`.

## Custom theme

Use the `theme` prop to customize the chatbot's design tokens.

```tsx id="m4r7sp"
<Chatbot
  theme={{
    primaryColor: "#2563eb",
    primaryForeground: "#ffffff",
    background: "#ffffff",
    foreground: "#111827",
    mutedBackground: "#f3f4f6",
    mutedForeground: "#6b7280",
    borderColor: "#e5e7eb",
  }}
/>
```

Theme values are applied to the chatbot's CSS variables.

You can override only the values you need:

```tsx id="c9x2kv"
<Chatbot
  theme={{
    primaryColor: "#7c3aed",
  }}
/>
```

The remaining values continue using the package defaults.

## Theme tokens

The theme API provides tokens for the main chatbot surfaces and controls.

| Token               | Purpose                                  |
| ------------------- | ---------------------------------------- |
| `primaryColor`      | Primary accent color                     |
| `primaryForeground` | Text color used on primary elements      |
| `background`        | Main chatbot background                  |
| `foreground`        | Main text color                          |
| `mutedBackground`   | Background used by secondary UI elements |
| `mutedForeground`   | Secondary text color                     |
| `borderColor`       | Border color                             |

A complete theme can look like:

```tsx id="w7m3nf"
const theme = {
  primaryColor: "#2563eb",
  primaryForeground: "#ffffff",
  background: "#ffffff",
  foreground: "#111827",
  mutedBackground: "#f3f4f6",
  mutedForeground: "#6b7280",
  borderColor: "#e5e7eb",
};
```

## Light and dark overrides

You can define values that apply specifically to each color mode.

```tsx id="a5q8xr"
<Chatbot
  theme={{
    primaryColor: "#7c3aed",
    primaryForeground: "#ffffff",
    light: {
      background: "#ffffff",
      foreground: "#18181b",
      mutedBackground: "#f4f4f5",
      mutedForeground: "#71717a",
      borderColor: "#e4e4e7",
    },
    dark: {
      background: "#18181b",
      foreground: "#fafafa",
      mutedBackground: "#27272a",
      mutedForeground: "#a1a1aa",
      borderColor: "#3f3f46",
    },
  }}
/>
```

The top-level values apply generally, while `light` and `dark` provide mode-specific overrides.

## Match your brand

A common setup is to use your application's primary brand color:

```tsx id="p3v6km"
<Chatbot
  theme={{
    primaryColor: "#7c3aed",
    primaryForeground: "#ffffff",
  }}
/>
```

You can combine this with custom light and dark surface colors:

```tsx id="h8r2wc"
<Chatbot
  theme={{
    primaryColor: "#7c3aed",
    primaryForeground: "#ffffff",
    light: {
      background: "#ffffff",
      foreground: "#18181b",
      borderColor: "#e4e4e7",
    },
    dark: {
      background: "#18181b",
      foreground: "#fafafa",
      borderColor: "#3f3f46",
    },
  }}
/>
```

## Custom CSS classes

When using the ready-made `<Chatbot />`, use `classNames` to attach your own classes to supported elements.

```tsx id="r5m9qx"
<Chatbot
  classNames={{
    wrapper: "custom-chatbot",
    trigger: "custom-trigger",
    window: "custom-window",
    header: "custom-header",
  }}
/>
```

The available keys are:

| Key       | Element              |
| --------- | -------------------- |
| `wrapper` | Root chatbot wrapper |
| `trigger` | Chat trigger         |
| `window`  | Chat window          |
| `header`  | Chat window header   |

You can then style those elements:

```css id="y4c7np"
.custom-window {
  border-radius: 24px;
}
```

The class names are applied alongside the package's own styles.

## Generated chatbot

The generated chatbot gives you direct access to its source and CSS.

Generate it with:

```bash id="z8w3km"
npx react-ai-chat init
```

You can then modify the generated CSS to make deeper visual changes.

For changes to the React structure itself, edit the generated components directly.

See [Generated Chatbot](/docs/guides/generated-chatbot).

## Theme mode in generated UI

The generated chatbot uses the same theme mode values:

```tsx id="f6q2xr"
<Chatbot themeMode="dark" />
```

```tsx id="b9m4vc"
<Chatbot themeMode="light" />
```

```tsx id="k3r7wp"
<Chatbot themeMode="auto" />
```

`auto` follows the user's system color preference.

## Keep themes accessible

When choosing custom colors, make sure text remains readable against its background.

For example:

```tsx id="s8n2qm"
<Chatbot
  theme={{
    primaryColor: "#2563eb",
    primaryForeground: "#ffffff",
  }}
/>
```

Test your custom colors in both light and dark modes when your application supports both.

## Complete example

```tsx id="m7x4kc"
import { Chatbot } from "react-ai-chat";
import "react-ai-chat/style.css";

export default function App() {
  return (
    <Chatbot
      title="AI Assistant"
      themeMode="auto"
      theme={{
        primaryColor: "#7c3aed",
        primaryForeground: "#ffffff",
        light: {
          background: "#ffffff",
          foreground: "#18181b",
          mutedBackground: "#f4f4f5",
          mutedForeground: "#71717a",
          borderColor: "#e4e4e7",
        },
        dark: {
          background: "#18181b",
          foreground: "#fafafa",
          mutedBackground: "#27272a",
          mutedForeground: "#a1a1aa",
          borderColor: "#3f3f46",
        },
      }}
    />
  );
}
```
