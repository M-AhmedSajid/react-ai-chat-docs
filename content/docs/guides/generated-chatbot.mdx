# Generated Chatbot

The `react-ai-chat` CLI can generate a complete chatbot UI directly inside your project.

Unlike the ready-made `<Chatbot />` component, the generated chatbot gives you source files that belong to your application. You can change the markup, styling, message rendering, input, header, trigger, and other UI details without modifying the package.

The generated UI uses `ChatbotProvider` and `useChatbotContext` from `react-ai-chat` for the chatbot logic.

## Generate the chatbot

Run:

```bash
npx react-ai-chat init
```

````

The CLI generates a TypeScript implementation.

For JSX instead:

```bash
npx react-ai-chat init --jsx
````

You can choose where the files are generated.

By default, the CLI generates the chatbot in:

```text
src/components/chatbot
```

You can provide a different directory with `--path`:

```bash
npx react-ai-chat init --path src/components/chatbot
```

To replace an existing generated chatbot:

```bash
npx react-ai-chat init --force
```

You can combine these options:

```bash
npx react-ai-chat init --jsx --path src/components/chatbot --force
```

See [CLI](/docs/guides/cli) for all available options.

## Generated files

The CLI generates these files:

```text
chatbot/
├── chatbot.tsx
├── chatbot-header.tsx
├── chatbot-messages.tsx
├── chatbot-input.tsx
└── chatbot.css
```

The exact directory depends on the `--path` option.

These are regular source files in your project. You can edit them like any other React components.

## How it works

The generated chatbot uses the package for chat state and API communication.

The structure looks like this:

```text
Your UI
   ↓
ChatbotProvider
   ↓
useChatbotContext()
   ↓
Chat API
   ↓
AI model
```

`ChatbotProvider` manages the chatbot state.

`useChatbotContext()` gives your components access to that state.

The generated UI decides how that state is rendered.

## Chatbot component

The generated `chatbot.tsx` file creates the provider and renders the UI:

```tsx
"use client";

import { ChatbotProvider, useChatbotContext } from "react-ai-chat";

import { ChatbotHeader } from "./chatbot-header";
import { ChatbotMessages } from "./chatbot-messages";
import { ChatbotInput } from "./chatbot-input";
import "./chatbot.css";

interface ChatbotProps {
  apiEndpoint?: string;
  position?: "bottom-right" | "bottom-left" | "top-right" | "top-left";
  initialOpen?: boolean;
  themeMode?: "auto" | "light" | "dark";
}

export function Chatbot({
  apiEndpoint = "/api/chat",
  position = "bottom-right",
  initialOpen = false,
  themeMode = "auto",
}: ChatbotProps) {
  return (
    <ChatbotProvider
      apiEndpoint={apiEndpoint}
      position={position}
      initialOpen={initialOpen}
      themeMode={themeMode}
    >
      <ChatbotUI />
    </ChatbotProvider>
  );
}
```

You can change this component to control the overall chatbot structure.

## Access chatbot state

Inside the generated UI, use `useChatbotContext()` to access the chatbot state.

For example:

```tsx
import { useChatbotContext } from "react-ai-chat";

export function MyComponent() {
  const { messages, input, setInput, isLoading, handleSubmit } =
    useChatbotContext();

  return (
    <div>
      <p>{messages.length} messages</p>

      <input value={input} onChange={(event) => setInput(event.target.value)} />

      <button onClick={handleSubmit} disabled={isLoading}>
        Send
      </button>
    </div>
  );
}
```

This lets you build your own UI around the package's chat logic.

See [`useChatbotContext`](/docs/api/use-chatbot-context) for the complete API.

## Customization

### Customize the header

The generated `chatbot-header.tsx` component controls the header.

The default implementation includes a title, subtitle, and close button.

You can replace the content with your own design:

```tsx
export function ChatbotHeader() {
  const { setIsOpen } = useChatbotContext();

  return (
    <header className="chatbot-header">
      <div>
        <h2>Project Assistant</h2>
        <p>Ask questions about this project</p>
      </div>

      <button
        type="button"
        onClick={() => setIsOpen(false)}
        aria-label="Close chatbot"
      >
        Close
      </button>
    </header>
  );
}
```

You can add your logo, status indicators, navigation, controls, or any other UI.

### Customize messages

The generated `chatbot-messages.tsx` component controls how messages are displayed.

The default implementation renders user messages as plain text and assistant messages with Markdown.

You can change the message layout:

```tsx
const { messages } = useChatbotContext();

return (
  <div>
    {messages.map((message) => (
      <div key={message.id}>
        {message.parts.map((part, index) => {
          if (part.type !== "text") return null;

          return <div key={index}>{part.text}</div>;
        })}
      </div>
    ))}
  </div>
);
```

This gives you control over:

- Message bubbles
- User and assistant layouts
- Markdown rendering
- Avatars
- Loading states
- Empty states
- Starter prompts
- Message actions

The generated code is a starting point. You can replace the message rendering with your own implementation.

### Customize the input

The generated `chatbot-input.tsx` component uses the chat context to manage the input value and submit messages.

The basic pattern is:

```tsx
const { input, setInput, handleSubmit, isLoading } = useChatbotContext();
```

You can then build your own input:

```tsx
<form onSubmit={handleSubmit}>
  <input
    value={input}
    onChange={(event) => setInput(event.target.value)}
    placeholder="Ask a question..."
    disabled={isLoading}
  />

  <button type="submit" disabled={isLoading || !input.trim()}>
    Send
  </button>
</form>
```

You can add your own buttons, attachments, icons, keyboard behavior, or layout.

### Customize the trigger

The generated chatbot opens and closes through `setIsOpen`.

For example:

```tsx
const { isOpen, setIsOpen } = useChatbotContext();

return (
  <button type="button" onClick={() => setIsOpen(!isOpen)}>
    {isOpen ? "Close chat" : "Open chat"}
  </button>
);
```

You can replace the generated trigger with any UI that fits your application.

### Customize styling

The CLI generates a `chatbot.css` file with the initial chatbot styles.

You can edit this file directly or replace the styling approach with your own system.

For example, you can use:

- Tailwind CSS
- CSS Modules
- Global CSS
- Your existing design system
- Plain CSS

The generated files are independent source code, so you can remove the generated styles and build your own.

## Configure the chatbot

The generated `Chatbot` component accepts configuration for the API endpoint, position, initial state, and theme mode.

```tsx
<Chatbot
  apiEndpoint="/api/chat"
  position="bottom-right"
  initialOpen={false}
  themeMode="auto"
/>
```

Available position values:

```ts
"bottom-right";
"bottom-left";
"top-right";
"top-left";
```

Available theme modes:

```ts
"auto";
"light";
"dark";
```

See [`ChatbotProvider`](/docs/api/chatbot-provider) for the complete provider API.

## Connect the API route

The generated UI still needs a server endpoint that handles the conversation.

Create the endpoint with `createChatRoute()`:

```tsx
import { google } from "@ai-sdk/google";
import { createChatRoute } from "react-ai-chat/server";

export const POST = createChatRoute({
  model: google("gemini-3.5-flash"),
});
```

Then point the generated chatbot to that endpoint:

```tsx
<Chatbot apiEndpoint="/api/chat" />
```

The default endpoint is:

```text
/api/chat
```

See [API Route](/docs/getting-started/api-route) for the complete setup.

## Add RAG

The generated UI works with RAG without requiring retrieval logic in the client.

Configure RAG on your server:

```tsx
import { createChatRoute } from "react-ai-chat/server";

export const POST = createChatRoute({
  model,
  rag: {
    index,
    provider,
    topK: 3,
  },
});
```

Your generated chatbot can continue using:

```tsx
<Chatbot apiEndpoint="/api/chat" />
```

The server handles retrieval before generating the response.

See [RAG](/docs/guides/rag) for the complete setup.

## Regenerate the chatbot

Running:

```bash
npx react-ai-chat init
```

does not replace existing generated files by default.

Use `--force` when you want to generate the chatbot again:

```bash
npx react-ai-chat init --force
```

Be careful when using `--force` after modifying the generated files. Your changes can be replaced.

Commit your customized chatbot before regenerating it if you need to preserve your changes.

## Generated code belongs to your project

After generation, the chatbot files are regular source files.

You can modify them, commit them, and deploy them with the rest of your application.

The package continues to provide the chatbot logic through:

```tsx
import { ChatbotProvider, useChatbotContext } from "react-ai-chat";
```

Your project owns the UI implementation.

## Ready-made vs generated chatbot

Use the ready-made `<Chatbot />` when you want a complete chatbot with configuration through props:

```tsx
import { Chatbot } from "react-ai-chat";
import "react-ai-chat/style.css";

<Chatbot apiEndpoint="/api/chat" />;
```

Use the generated chatbot when you want to control the implementation:

```bash
npx react-ai-chat init
```

The generated version gives you direct access to the UI source code while the package continues to handle the chat state and API communication.
