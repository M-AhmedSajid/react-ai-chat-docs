# CLI

`react-ai-chat` includes a CLI for two tasks:

- Generate an editable chatbot UI
- Create an embedding index for RAG

You can run it directly with `npx`:

```bash
npx react-ai-chat
```

## Command overview

| Command                                   | Purpose                                                   |
| ----------------------------------------- | --------------------------------------------------------- |
| `npx react-ai-chat init`                  | Generate an editable chatbot UI                           |
| `npx react-ai-chat --<provider>`          | Create a RAG embedding index                              |
| `npx react-ai-chat --provider <provider>` | Create a RAG embedding index using the specified provider |
| `npx react-ai-chat --help`                | Show CLI help                                             |

Supported embedding providers:

- `google`
- `openai`
- `voyage`
- `cohere`
- `jina`
- `huggingface`

## Generate a chatbot

Use `init` to generate an editable chatbot implementation in your project:

```bash
npx react-ai-chat init
```

The CLI generates TypeScript React files by default:

```text
chatbot/
├── chatbot.tsx
├── chatbot-header.tsx
├── chatbot-messages.tsx
├── chatbot-input.tsx
└── chatbot.css
```

These are regular source files in your project. You can change their markup, styling, and behavior without modifying the package.

The generated UI uses:

```tsx
import { ChatbotProvider, useChatbotContext } from "react-ai-chat";
```

The package provides the chatbot state and actions while your project owns the UI implementation.

See [Generated Chatbot](/docs/guides/generated-chatbot) for the complete customization guide.

### Generate JSX

For JavaScript or JSX projects, use `--jsx`:

```bash
npx react-ai-chat init --jsx
```

This generates JSX files instead of TSX files.

### Choose an output directory

Use `--path` to choose where the generated files should be placed:

```bash
npx react-ai-chat init --path src/components/chatbot
```

For example:

```text
src/
└── components/
    └── chatbot/
        ├── chatbot.tsx
        ├── chatbot-header.tsx
        ├── chatbot-messages.tsx
        ├── chatbot-input.tsx
        └── chatbot.css
```

The path is resolved relative to your current working directory.

### Overwrite generated files

The CLI does not overwrite existing generated files by default.

Use `--force` when you want to replace them:

```bash
npx react-ai-chat init --force
```

You can combine it with other options:

```bash
npx react-ai-chat init --jsx --path src/components/chatbot --force
```

Be careful when using `--force` because existing generated files can be replaced.

## Generate a RAG index

The CLI can create an embedding index from your content.

Choose an embedding provider and run:

```bash
npx react-ai-chat --google
```

The default workflow is:

```text
./content
    ↓
Load documents
    ↓
Chunk documents
    ↓
Generate embeddings
    ↓
./chatbot/embeddings.json
```

The default paths are:

```text
Content: ./content
Output:  ./chatbot/embeddings.json
```

The generated JSON contains the embedding index used by the server-side RAG flow.

See [RAG](/docs/guides/rag) for how to connect the generated index to your chat route.

## Embedding providers

The CLI supports six embedding providers.

### Google

```bash
npx react-ai-chat --google
```

### OpenAI

```bash
npx react-ai-chat --openai
```

### Voyage

```bash
npx react-ai-chat --voyage
```

### Cohere

```bash
npx react-ai-chat --cohere
```

### Jina

```bash
npx react-ai-chat --jina
```

### Hugging Face

```bash
npx react-ai-chat --huggingface
```

You can also select a provider with `--provider`:

```bash
npx react-ai-chat --provider google
```

For example:

```bash
npx react-ai-chat --provider openai
```

The provider option selects the same embedding provider as the dedicated provider flags.

## Customize paths

The RAG command accepts the content path as its first positional argument and the output path as its second positional argument.

### Custom content path

```bash
npx react-ai-chat --google ./docs
```

This reads documents from:

```text
./docs
```

The output remains:

```text
./chatbot/embeddings.json
```

For example:

```text
docs/
├── getting-started.md
├── installation.md
└── api.md
```

### Custom output path

Pass the output path as the second positional argument:

```bash
npx react-ai-chat --google ./content ./data/embeddings.json
```

You can also use `--output`:

```bash
npx react-ai-chat --google --output ./data/embeddings.json
```

The short form `-o` is supported:

```bash
npx react-ai-chat --google -o ./data/embeddings.json
```

### Customize both paths

Use both positional arguments:

```bash
npx react-ai-chat --google ./docs ./data/embeddings.json
```

This means:

```text
Source documents → ./docs
Embedding index  → ./data/embeddings.json
```

You can also use `--output`:

```bash
npx react-ai-chat --google ./docs --output ./data/embeddings.json
```

The explicit `--output` or `-o` value takes priority over the second positional argument.

## Environment variables

Each embedding provider requires its API credentials.

### Google

```text
GOOGLE_GENERATIVE_AI_API_KEY=your_api_key_here
```

### OpenAI

```text
OPENAI_API_KEY=your_api_key_here
```

### Voyage

```text
VOYAGE_API_KEY=your_api_key_here
```

### Cohere

```text
COHERE_API_KEY=your_api_key_here
```

### Jina

```text
JINA_API_KEY=your_api_key_here
```

### Hugging Face

```text
HF_TOKEN=your_api_token_here
```

The CLI loads environment variables before processing the command.

## Example project structure

A project using generated chatbot files and a RAG index could look like this:

```text
my-project/
├── content/
│   ├── introduction.md
│   ├── installation.md
│   └── api.md
├── chatbot/
│   ├── chatbot.tsx
│   ├── chatbot-header.tsx
│   ├── chatbot-messages.tsx
│   ├── chatbot-input.tsx
│   ├── chatbot.css
│   └── embeddings.json
└── app/
    └── api/
        └── chat/
            └── route.ts
```

Generate the chatbot:

```bash
npx react-ai-chat init --path chatbot
```

Generate the embedding index:

```bash
npx react-ai-chat --google ./content ./chatbot/embeddings.json
```

Your API route can then load the generated index and use it for RAG.
